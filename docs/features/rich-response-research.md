All listed repositories had recent commits and were not archived when checked. That does not establish production readiness. In particular, adding only a desktop React renderer would not satisfy Codync's mobile and terminal requirements. No model-generated JavaScript should run inside ordinary message rendering; existing explicitly published HTML artifacts have a separate isolated trust model.

The host must continue to own durable content, authorization and validation. A structured format needs a version, strict bounded schemas and meaningful text fallback for unknown clients. Cite sources the agent actually supplies; a displayed URL is not proof the source was consulted or that its claims are true. Interactive actions additionally need explicit user intent and existing host permissions. Screen reader behavior, malformed and very large input, reduced motion, reconnect, interruption and old-client fallback need device-level verification before claiming full support.
